Unsupervised Find structure without labels.

K-Means Clustering

Groups unlabelled points into k clusters by repeatedly moving k centres to the middle of their points.

89.3% clusters match speciesTry it →

Principal Component Analysis

Rotates the data to find the few directions that capture most of its variation, so you can keep those and drop the rest.

29 of 64 components for 95% varianceTry it →

Your own data

Train any of these models on your data

The repository can try every model on your CSV, report an honest score, and warn you about leakage.

git clone https://github.com/Nihar16/MACHINE-LEARNING-MODELS.git
cd MACHINE-LEARNING-MODELS
pip install -r "Setup files/requirements.txt"

python automl.py --data your_data.csv --target column_to_predict      # try every model
python models/12_cnn/train.py --data my_images                        # images: one folder per class
